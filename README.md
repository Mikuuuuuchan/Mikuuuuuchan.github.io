# 个人主页

一个使用原生 HTML 和 CSS 构建的个人主页。

## 本地预览

1. 下载或克隆本项目。
2. 打开项目目录。
3. 使用浏览器打开 `index.html`。

也可以使用 VS Code 等编辑器打开项目，并通过本地静态服务器预览。

## 文件结构

- `index.html`：页面结构与内容
- `style.css`：页面样式
